`hooterjackson/HomeApp`, public. The whole repository is **one commit** —
`b769b30`, 2026-06-12, "Deploy current Home app snapshot".

That single fact governs how this project can be tracked. Evidence rules that
depend on commit history — "did anything land since this thread" — return
nothing here and always will, and returning nothing is not the same as nothing
having happened. Any item in this project needs a file-level or dated-manual
evidence rule instead. APP-001 exists to make that concrete rather than to leave
it as a caveat somebody rediscovers.
